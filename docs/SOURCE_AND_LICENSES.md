# Source and License Boundary

The single-query pool contains 7,713 candidates: 6,660 public background skills and 1,053 deduplicated admitted-pair candidates. The background records 5,862 MIT and 798 Apache-2.0 repository declarations; these are not license totals for the entire pool. Unit and component terms govern constructed candidates.

Repository-level labels do not override nested notices. Thirty-six units with explicitly incompatible redistribution/modification terms were excluded before freeze. CHAMP code and task material have different stated scopes; the latter's research/noncommercial boundary remains unresolved for public redistribution.

The current local candidate is therefore not a blanket relicensing of upstream text. Final access must preserve exact notices or use a permitted reconstruction route whose output matches frozen hashes.
